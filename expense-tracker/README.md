Personal Expense Tracker

A simple, responsive expense tracker built with HTML, CSS and JavaScript.

## Features

- Add income and expenses
- Calculate current balance automatically
- View total income and expenses
- Delete transactions
- Filter transactions by type
- Choose transaction category
- Select transaction date
- Data persists using browser LocalStorage
- Dark/light mode
- Responsive design for mobile and desktop
- No backend or database required

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start adding transactions.

No installation or build process is required.

## Deploy on Netlify

1. Upload this project to GitHub.
2. Sign in to Netlify.
3. Select **Add new project → Import an existing project**.
4. Connect your GitHub repository.
5. Leave the build command empty.
6. Set the publish directory to `/` (or the project root).
7. Deploy.
